# OVERCLOCK — большая песочница-лаборатория-роглайк для Dota 2

`OVERCLOCK` — кастомная игра (custom game, Workshop Tools addon) для Dota 2.
Один большой аддон, который объединяет три вещи:

1. **Sandbox** — песочница: спавн любых юнитов/героев, уровни, золото, предметы,
   таланты, аганим, управление временем и камерой.
2. **Balance / Patch Lab** — своя правка баланса: хот-применение оверрайдов
   способностей/героев/предметов, наборы патчей и A/B-сравнение в одной сессии.
3. **Roguelike «Испытание»** — превращает Доту в роглайк: процедурные волны,
   «проклятия» (heat), межраундовый магазин, мета-прогрессия с сохранением.

Плюс сквозные подсистемы:

* **Движок модификаторов** — data-driven лua-модификаторы со стаками, длительностью,
  диспелами и аурами.
* **Метрология** — DPS-метр, лог урона по источникам/типам, TTK, EHP, тайминги.
* **Panorama UI** — хаб, панели песочницы, консоль модификаторов, редактор патчей,
  дашборд статистики, настройка рана, настройки, локализация ru/en.

> **Дота не ломается.** Аддон живёт строго в `dota_addons` и грузится только при
> запуске через «Custom Games» / Workshop Tools. Базовые файлы игры
> (`game\dota\`, `pak01_*.vpk`) не трогаются вообще.

## Быстрый старт

1. Собери карту и запусти аддон — см. **[BUILD_GUIDE.md](BUILD_GUIDE.md)**.
2. В игре открой хаб клавишей **F5**, песочницу — **F6**, статистику — **F7**,
   редактор патчей — **F8**, роглайк — **F9**, консоль модификаторов — **F10**.

## Что уже реализовано

- **Ядро**: логгер, шина событий, таймеры, состояние, конфиг, команды, игроки.
- **Песочница**: спавн юнитов/героев/манекенов, контроль героев (уровень,
  способности, аганим/шард, респавн), контроль времени (пауза/скорость),
  камера, выдача предметов.
- **Модификаторы**: data-driven реестр + движок (стаки, длительность, ауры) и
  9 Lua-модификаторов (замедление, DoT, проклятия брони/маны, баффы атаки/щита,
  стат-бонусы, манекен, универсальная аура).
- **Метрология**: лог урона (фильтр движка), скользящий DPS/пик, измерение и
  предсказание TTK, расчёт EHP.
- **Patch Lab**: 6 наборов «правок баланса», применение/сброс, замер и A/B.
- **Роглайк**: конечный автомат рана (проклятие → бой → награда → магазин),
  процедурные волны, каталог проклятий/награды/магазин, мета-прогрессия.
- **UI**: Panorama-оверлей (хаб/песочница/статистика/патчи/роглайк/параметры),
  мост Lua↔Panorama, привязка клавиш F5–F10, локализация ru/en.
- **Живые параметры**: реестр `core/params.lua` + `data/tunables.lua` — все
  настройки (время, метрики, манекен, герой, роглайк, арена, отладка) правятся
  на лету из вкладки **Параметры** или командами `-params` / `-set <id> <value>`.

## Инструменты

Статическая проверка всего, что проверяется без Dota:

```bash
python3 tools/validate.py
```

Проверяет: Lua (luaparser, если стоит), JS (`node --check`), XML (well-formed),
баланс скобок в KV/локализации и разрешимость всех `require(...)`.

## Живые параметры (внутриигровой интерфейс)

Вкладка **Параметры** (кнопка в оверлее) строится автоматически из реестра:
для каждого параметра рисуется контрол по типу —
`−/+` (числа с шагом/границами), `вкл/выкл` (флажки), переключение (enum),
кнопка-действие. Любое изменение уходит на сервер и применяется мгновенно,
после чего список перерисовывается с новыми значениями.

Дублируется командами в чате:
`-params` (список) и `-set <id> <value>` (например, `-set time_scale 0.5`).

Чтобы добавить новый параметр — одна запись в `data/tunables.lua`:

```lua
Params.register({
    id = "my_param", label = "Моя настройка", section = "Отладка",
    type = "number", min = 0, max = 10, step = 0.5,
    get = function() return Config.tuning.my_param end,
    set = function(v) Config.tuning.my_param = v end,
})
```
